# Deal Intelligence Agent

An AI-assisted sales intelligence prototype developed for **Hack Baroda**.

Deal Intelligence Agent explores how organizational memory, stakeholder intelligence, objection analysis, and context-aware recommendations can help sales teams understand deals and make better-informed decisions.

## Overview

Sales teams often need to understand deal history, identify stakeholder concerns, and decide how to approach objections. This prototype explores ways to organize deal-related information and use relevant historical context to support sales strategy.

The application brings together sales intelligence concepts in an interactive interface for exploring deals, stakeholders, objections, and potential strategies.
